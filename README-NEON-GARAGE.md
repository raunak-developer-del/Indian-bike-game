# Indian Ride Simulator 3D — Neon Garage 2.1

Keep `index.html`, `manifest.webmanifest`, `sw.js`, and `icon.svg` together in the same GitHub Pages folder. `index.html` is the replacement homepage and game.

Publish from GitHub Pages on HTTPS. Three.js loads from a CDN, so the first load needs internet access.

Controls: WASD / arrow keys; Space to accelerate; S / down arrow to brake. On tablets, use the on-screen controls. The Garage homepage has vehicle categories, a preview panel, vehicle unlocks, and a once-per-local-day 250-coin prize.
